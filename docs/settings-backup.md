# 设置备份与增强设置布局

设置首页标题栏从左到右为搜索、导出配置、导入配置、三点菜单。导入和导出使用图标，保留鼠标提示和无障碍名称。

## 备份范围

| 类别 | 实际内容 |
| --- | --- |
| 普通设置 | 通知、聊天显示、输入、播放、通话设备、翻译、拼写、窗口、主题强调色、账号顺序、最近表情等显式登记的偏好 |
| 增强设置 | 原增强配置导出字段及本地屏蔽列表 |
| 账号本地设置 | 按账号 ID 匹配的自动下载及默认值继承、下载例外、缓存限额、归档、支持模式、电话显示、提示音音量、表情收藏、分区标签 |
| 快捷键 | 命令与可移植按键序列，包括移除默认绑定和一键多命令 |
| 实验选项 | 当前平台相关的实验选项，包含默认值；导入同步内存和文件 |
| 外观 | 已保存日夜主题、当前背景原图及另一模式的现代背景记录；图片使用 PNG |
| 系统 | 语言包及自定义翻译、缩放、更新、节能、启动选项；开机启动通过系统接口应用 |
| 代理 | 服务器、类型、端口、凭据、轮换与连接选项；必须加密 |
| 云端 | 14 类隐私规则、全局隐私、三类默认通知、通知例外、回应通知、默认消息自动删除期限及普通文件夹顺序；必须加密，导入默认不勾选 |

这是配置备份，不是 tdata 或账号镜像。登录授权、两步验证密码、本地锁密钥、系统解锁授权、钱包密钥、支付信任、聊天记录、下载文件和缓存内容不导出。提示是否看过、最近使用记录中的部分状态及服务端业务配置也不作为完整迁移目标。

云端当前使用带 API layer 的类型化 TL 负载。仅同 layer、同账号恢复；不兼容负载跳过，其他本地类别仍可导入。共享文件夹跳过并报告。通知例外和文件夹按备份条目更新，不删除目标端额外条目；业务自动回复、账号资料、已屏蔽用户等服务端状态不在当前云端适配器范围。主题云端身份转换为便携主题内容，非当前模式的旧版背景记录需要先在客户端打开该模式并保存。

## 格式与恢复

外层为 `format=telegram-settings`、`version=1` 的 JSON，按类别放在 `sections`。账号使用包含正式/测试环境标志的稳定 ID。64 位整数使用十进制字符串，避免 JSON 数字精度丢失；二进制字段使用 Base64。缺失字段保留当前值，未知字段跳过，非法类型、枚举和越界值拒绝。旧增强 JSON 仍可导入。

加密格式为 `TDSETTINGS1` 加换行、16 字节随机盐、12 字节随机 nonce、16 字节认证标签及 AES-256-GCM 密文。密钥使用 PBKDF2-HMAC-SHA256、600000 次迭代派生。密码至少 8 个字符。加解密在后台执行；文件上限 128 MiB，写出使用 QSaveFile 原子替换。

导入展示各类别变更数量和跳过数量，不展示代理密码等敏感值。云端恢复先执行并单独报告部分失败，再应用所选本地类别；云端 API 不提供事务和自动回滚。每个云端步骤有超时限制，超时后的实际服务端状态需重新核对。

本地写入前保存所选类别的恢复快照，使用账号本地存储密钥加密。发生写入错误时尝试恢复，恢复失败保留快照；下次解锁账号后提示恢复。恢复依赖原本地账号和 tdata，不能替代异地备份。本地保存成功后重启，使依赖启动初始化的设置生效。

## 增强设置分类

聊天与显示、消息操作、消息过滤与链接、搜索与翻译、导航与快捷键、输入与编辑按钮、消息右键菜单、媒体与播放、网络与下载、语音聊天、性能与诊断。此页面仅重排控件和分组标题，保留配置键、默认值、回调和搜索定位。

## 验证与使用建议

本机无构建环境，编译以 GitHub Actions 的 Windows 工作流为准。提交前进行增量 C++ 语法分析、头文件及生成协议符号核对、语言键和图标资源核对、CRLF/无 BOM 检查及 git diff --check；原 Core::Settings 和 SessionSettings 的顺序二进制序列化方法保持不变。

首次使用应先导出加密备份，再在备用客户端测试导入。建议先恢复本地配置，确认同账号匹配和设备路径后再选择云端类别。跨电脑需核对字体、音视频设备、下载目录及外部播放器路径。发布前运行验收包含：旧增强 JSON、默认设置往返、密码错误和密文损坏、未知字段、账号缺失、写入失败恢复、重启持久化、云端超时、窄窗口图标布局。静态检查不替代这些运行态验证。
